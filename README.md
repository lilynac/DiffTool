# SheetDiff

このリポジトリを clone したフォルダを作業場所として使用します。比較対象の個人データや作業環境固有の設定は、リポジトリに含めないでください。

Windows / macOSで動くPython製デスクトップ比較ツールの初版です。

## 開発状況

**開発中です。** 現在は初期版で、機能や画面、対応形式は今後の開発で変更される場合があります。Windows 実機での動作確認はまだ行っていません。利用前に「対応範囲」と「現時点の制約」を確認してください。

## 起動

Python 3.11以降をインストールして、このフォルダで実行します。

Windows（PowerShell）:

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python main.py
```

macOS:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

セットアップ後は、Windowsは `start_windows.bat`、Macは `start_mac.command` をダブルクリックして起動できます。この作業環境のMacではセットアップ済みです。別のPCではOSに合った仮想環境を作成してください。

ファイルを引数でも指定できます：`python main.py left.xlsx right.xlsx`

## 使い方

1. 左右のファイルを選択、またはパス欄へドロップします。
2. 必要な比較オプションを指定して「比較する」を押します。
3. Excelは左の一覧でシートを選びます。同名シートが自動で対応します。
4. F7 / Shift+F7で現在のシートの次 / 前の差分に移動します。
5. 表の行をクリックすると、下部のDiffペインに左・右の行が上下に並びます。文字単位の変更箇所も色分けします。
6. シート一覧と比較表の間にあるロケーションペインで、全体の差分位置と現在の表示範囲を確認できます。クリック・ドラッグで該当行へ移動します。検索・差分絞り込み中は表示行を対象にします。
7. 「差分だけ表示」や検索で絞り込みます。「差分CSVを保存」は絞り込みに関係なく全シートの差分を書き出します。

黄色は変更、緑は右への追加、赤は左から削除、灰色は対応する行がないことを示します。
スクロールと列幅は左右で同期します。Ctrl+C（MacはCommand+C）で選択行をコピーできます。

## 対応範囲

- `.txt` など：行の追加・削除を対応づけて左右表示。改行を `↵`、CRを `␍` で表示し、改行コードや末尾改行の違いも検出します。
- `.csv` / `.tsv`：CSVの引用符・セル内改行を解析して列単位で比較。CSVはカンマ、TSVはタブ区切りです。行番号は論理レコード番号です。
- `.xlsx` / `.xlsm`：同名シートごとに行の内容を対応づけてセル値を比較。途中の行挿入・削除は片側を空欄にして表示します。左右にはそれぞれ元ファイルの行番号を表示します。片側だけのシートも表示します。非表示シートも対象です。
- 文字コード：UTF-8 / BOM付きUTF-8 / BOM付きUTF-16 / CP932を自動判定。手動選択も可能です。
- 空白無視は文字列中の全空白を除去します。文字列と数値、真偽値は区別します。
- Excelは初期設定で数式そのものを比較します。「保存済み計算結果」はExcelが保存したキャッシュを読みます。数式を再計算しません。キャッシュのない数式は空欄になり、このモードでは数式変更を検出できないことがあります。
- Excelの末尾の空セル・空行は比較から除外します。書式だけが存在するセルも比較対象外です。

## 現時点の制約と今後の拡張

WinMerge同等の完成版ではありません。元ファイルを編集せず読み取る比較機能が中心です。

- 未対応：左右へのマージ・編集、フォルダ比較、メイン表内での文字単位ハイライト（下部Diffペインでは対応）、旧Excel `.xls`、書式・画像・グラフ・コメント・結合状態・マクロの比較。
- 「Excelの行挿入・削除を検出」は初期状態でオンです。オフにすると従来のセル位置比較になります。オプション変更後は「比較する」を押してください。
- 行の対応づけは一致行を基準にし、その間の変更行はセルの一致度で推定します。完全に同じ重複行や、全セルが変わった行は対応が曖昧になる場合があります。大きな変更区間は一意なセル値を手掛かりにし、手掛かりがない場合は位置で対応づけます。キー列の手動指定・行の並べ替え検出は未対応です。
- 数式は対応づけ後に比較します。同じシート内のA1形式のセル参照は、行移動に伴う行番号変更を補正します。範囲参照は範囲内の全行が同じ量だけ移動した場合のみ補正します（1万行を超える範囲は対象外）。別シート・外部ブック・構造化参照は文字列として比較します。元の式はDiffペインにそのまま表示します。
- 列の挿入・削除は未対応で、後続列にも差分が出ます。
- CSVの列挿入も位置による比較です。セミコロン区切りの自動判定はありません。
- 全データをメモリに保持します。上限はテキスト50MB、Excelは書式領域を含め1ファイル200万セルです。上限内でもデータによって処理に時間がかかります。比較はバックグラウンドで実行しますが途中キャンセルは未実装です。
- 自動文字コード判定が適さない場合は手動指定してください。
- Windowsでの実機確認は未実施です。

## 配布用アプリの作成（任意）

配布先と同じOS上でビルドします。macOSからWindows用exeは作成できません。

```sh
python -m pip install pyinstaller
python tools/build_app.py
```

`dist` 以下に独自アイコン付きの成果物が作られます。Macは `dist/SheetDiff.app`、Windowsは `dist/SheetDiff/SheetDiff.exe` から起動します。開発者証明書による署名・公証・インストーラー作成は含みません。ソースを変更したら再ビルドしてください。

アイコンの原本は `assets/sheetdiff.svg` です。`tools/build_icons.py` でPNG・Windows用ICO・Mac用ICNS（Mac上のみ）を生成します。通常のPython起動でもウィンドウアイコンを設定します。

## 比較サンプル

`outputs/excel-comparison-samples` の「比較元_変更前.xlsx」と「比較先_変更後.xlsx」を左右に指定してください。

- 売上：500件 → 520件。数量・単価・商品名・数式の変更と末尾20件の追加。
- 在庫：500件 → 480件。在庫数・保管場所・備考の変更と末尾20件の削除。
- 変更なし：100件の同一データ。
- 廃止商品 / 新商品：片側だけのシート。

件数は見出し行を除きます。初期設定（数式比較）では売上51行、在庫46行に差分が出ます。

## Macで起動直後に終了する場合

今回の環境では、QtのプラグインファイルにmacOSの非表示属性が付いており、Qtが検出できませんでした。起動前にプラグインの非表示属性だけを解除する処理を追加しています。PySide6は通常起動を確認した6.10.2に固定しています。

Macの起動スクリプトは失敗時の出力を `logs/startup.log` に保存します。別の環境でライブラリ自体が壊れている場合は、仮想環境のPythonで `python -m pip install --force-reinstall -r requirements.txt` を実行してください。

実装時の参照：[Qtのスレッドとシグナル](https://doc.qt.io/qtforpython-6/examples/example_widgets_thread_signals.html)、[openpyxl](https://openpyxl.readthedocs.io/en/stable/)。
